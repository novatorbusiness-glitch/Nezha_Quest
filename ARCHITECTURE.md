## 🥷 КОНЦЕПЦИЯ И НАРРАТИВ

### Суть
Артём — это **Нэчжа**. Бунтарь с огнём внутри, который выбирает стать героем.
Его реальная жизнь — это **испытания духа**. Рутина — это **тренировки**.
Родители — **Сенсей Илья и Сенсей Аня** — не враги. Они Мастера. Правила устанавливает **Система Додзё**, не люди. За нарушения наказывает Кодекс — не мама.

**Главный посыл для Артёма:**
> «Нэчжа не слушается правил потому что они чужие. Но когда он сам выбирает путь героя — никто не может его остановить. Твои правила — твой путь.»

### Три ценности → Три механики
| Ценность | Механика | Валюта |
|----------|----------|--------|
| Честность | HP (Здоровье духа) | Падает за ложь, растёт за признание |
| Дисциплина | XP (Опыт/Сила) | Дейлики, стабильный рост |
| Трудолюбие | 💎 Кристаллы Лотоса | Инициатива, тяжёлая работа |

```
      type: "quest_approved" | "penalty_triggered" | "item_bought" | "respect_given"

      detail: String
```

### Security Rules (Firebase)
```json
{
  "rules": {
    "nezha-quest": {
      "state": {
        "penalty": {
          ".write": "newData.child('active').val() === false ? data.child('spun').val() === true : true"
        }
      }
    }
  }
}
```
> Критическое правило: снять блокировку (`active: false`) можно только если `spun: true`. Артём не может сам снять бан.

### Экран 4: АРЕНА ТЬМЫ (Штрафы)

**Видна только если `penalty.active = true`**

Оверлей полностью перекрывает экран. Тёмно-красный фон, анимация «молния + трещины».

**Логика штрафов:**

Мастер выбирает категорию при активации:
- `light` / `medium` → запускается **Колесо Последствий** (рандом из 20 штрафов)
- `hard` → выдаётся **фиксированный штраф** (выбирает Мастер вручную из 10)

Артём не может закрыть этот экран пока:
1. Не покрутил колесо
2. Не нажал «Я ПРИНЯЛ ПОСЛЕДСТВИЕ»

### Экран 5: ПУЛЬТ МАСТЕРОВ (Admin) — только по PIN

**Секции:**

1. **Очередь на проверку** — список pending квестов
   - [✓ ЗАЧЕСТЬ] → XP + кристаллы зачисляются, firebase sync
   - [↩ ВЕРНУТЬ] → с заметкой от Мастера, возвращается как rejected

2. **Кнопка УВАЖЕНИЕ** — нажать когда Артём сделал что-то хорошее без просьбы
   - Выдаёт «Сундук Сенсея» — рандомная награда
   - Без кристаллов, просто жест

3. **КРИТИЧЕСКИЙ УДАР** — за ложь
   - Выбор категории: Лёгкий / Средний / Жёсткий
   - Жёсткий — показывает список из 10 штрафов, Мастер выбирает конкретный
   - Подтверждение → `penalty.active = true` → firebase → Артём видит блокировку МГНОВЕННО

4. **РЕДАКТОР ПРАВИЛ** — изменить квесты, цены, награды

5. **ЛОГ СОБЫТИЙ** — история действий за последние 30 дней

## ⚙️ КЛЮЧЕВЫЕ МЕХАНИКИ

### Combo/Streak система
```
3 дня подряд → «Серия Воина» → +10% XP к каждому дейлику
7 дней подряд → «Неделя Огня» → +20% XP + специальный значок
14 дней подряд → «Манифест Нэчжа» → разблокируется особое достижение
30 дней подряд → Эпик награда от родителей
```

Пропустил один дейлик → серия сбрасывается. Это важно — даёт мотивацию не прерываться.

### Коты Додзё
На дашборде — два кота (иконки). Если `d2` (накормил котов) не выполнен к 18:00:
- Иконки переходят в состояние «голодные» (серые, анимация дрожания)
- Автоматический `-5 HP` без участия Мастеров

### Ночной режим (timers.js)
```js
// Каждую минуту проверяем время
function checkNightMode() {
  const now = new Date();
  const hour = now.getHours();
  const isNight = hour >= 21 || hour < 7;
  
  if (isNight !== state.nightMode) {
    state.nightMode = isNight;
    document.body.classList.toggle('night-mode', isNight);
    saveState();
  }
}
```

### Сброс дейликов (timers.js)
```js
function checkDailyReset() {
  const today = new Date().toDateString();
  if (state.lastDailyReset !== today) {
    // Если дейлики вчера не все выполнены — streak сбрасывается
    const completedYesterday = checkYesterdayCompletion();
    if (!completedYesterday) state.hero.streakDays = 0;
    
    // Сбрасываем статусы дейликов
    state.quests.dailies.forEach(q => {
      if (q.status !== 'pending') q.status = 'todo';
    });
    state.lastDailyReset = today;
    saveState();
  }
}
```

### Штрафной поток (строгий)
```
Мастер выбирает категорию нарушения:
  "light"/"medium" → state.penalty = { active: true, category, spun: false }
  "hard"           → state.penalty = { active: true, category: "hard", fixedPenalty: "...", spun: false }
  → firebase.set('/state/penalty', ...)
  → Артём МГНОВЕННО видит оверлей Арены

Артём крутит колесо:
  wheel.spin() → возвращает Promise с результатом
  → state.penalty.result = result
  → state.penalty.spun = true
  → firebase sync

Артём принимает штраф:
  if (state.penalty.spun === true):
    → state.penalty = { active: false, ... }
    → state.hero.hp = 100
    → firebase sync (правило безопасности пропускает)
    → log.push({ type: "penalty_resolved", ... })
```

## 🏗️ ДОРОЖНАЯ КАРТА — ШАГИ РАЗРАБОТКИ

### Шаг 1: Shell + Дизайн-система + Дашборд
- `index.html` — базовый shell, все секции
- `tokens.css`, `base.css` — тёмная тема Нэчжа
- `avatar.js` — SVG аватар с состояниями по HP
- `hud.js` — бары HP/XP/Кристаллы
- `dashboard.js` — дашборд с котами, таймером, streak
- `timers.js` — ночной режим

### Шаг 2: Квест-система
- `data/quests.js` — все квесты
- `state.js` — localStorage стейт
- `modules/quests.js` — логика
- `screens/quests.js` — рендер

### Шаг 3: Экономика + Магазин + Колесо Фортуны
- `economy.js` — XP/HP/кристаллы операции
- `wheel.js` — переиспользуемый класс колеса
- `data/rewards.js`, `data/shop.js`
- `screens/shop.js`

### Шаг 4: Арена Тьмы + Штрафной оверлей
- `data/penalties.js`
- `screens/arena.js`
- Оверлей с колесом последствий

### Шаг 5: Пульт Мастеров + Auth
- `auth.js` — PIN
- `screens/admin.js` — очередь, крит-удар, уважение, редактор

### Шаг 6: Firebase Sync
- `firebase.js` — realtime sync
- Security Rules
- Тест на двух устройствах: мамин телефон (Мастер) + макбук (Артём)

### Шаг 7: PWA + Полировка
- `manifest.json`, `sw.js`
- Карта Додзё (изометрическая навигация)
- Toast-уведомления
- Тест streak-системы
- Combo-анимации при получении xp

## ⚠️ ВАЖНЫЕ ПРИНЦИПЫ (Не нарушать)

1. **Жёсткие штрафы за ложь — фиксированные, не рандом.** Рандом деморализует, фиксированный — учит ответственности.
2. **Система наказывает, не родители.** Вся риторика интерфейса — нейтральная, системная. Никаких «мама расстроена».
3. **Снять блокировку нельзя без колеса.** Firebase Security Rule — железно.
4. **Ночной режим не даёт сабмитить квесты после 21:00.** Иначе он будет отправлять всё за 5 минут до сна.
5. **Streak дороже разовых наград.** Комбо-система — главная психологическая зацепка.
